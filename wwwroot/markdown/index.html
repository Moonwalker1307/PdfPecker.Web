Markdown help

    
  

  

    

      
Writing

      

        
# HeadingHeading (## to ###### for smaller ones)

        
**bold** *italic*Bold and italic

        
~~struck~~Strikethrough

        
`code`Inline code; three backticks on their own line start a code block

        
[text](https://…)Link; paste a URL over selected text to make one

        
![alt](image.png)Image; paste or drop an image to embed it

        
- item 1. itemLists; Enter continues them, Tab nests an item

        
- [ ] taskTask list item; - [x] is done

        
> quoteQuote

        
| a | b |Table, with | --- | --- | under the header row

        
---Horizontal rule

        
<div>…</div>HTML works too; style it with Extra CSS in the PDF settings

      

    

    

      
Keyboard shortcuts

      

        
Ctrl+BBold

        
Ctrl+IItalic

        
Ctrl+Shift+XStrikethrough

        
Ctrl+EInline code

        
Ctrl+KLink

        
Ctrl+ZUndo

        
Tab / Shift+TabNest or un-nest a list item; next table cell

        
Esc then TabLeave the editor

        
Ctrl+EnterConvert

        
Ctrl+/This help

      

      
On a Mac, use ⌘ for Ctrl. In the visual editor, typing #, -, 1.,
        [ ], > or ``` and a space at the start of a line formats it.

      
Your document is saved in this browser as you type and comes back when you return. It is only sent
        to the server to convert it, and never stored there.

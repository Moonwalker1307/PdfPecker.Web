PdfPecker turns HTML and Markdown into PDFs, and PDFs into images, from plain .NET. No browser to start, no native binaries to ship, no third-party packages. Just one small DLL.

Three lines to your first PDF

Every method is static and thread-safe, so you can convert many documents at once. Write the HTML the way you already do, with modern CSS, and get a PDF back as bytes, a stream or a file.

  • Runs wherever .NET 10 runs: Windows, Linux, macOS, x64 and ARM64, containers and serverless
  • Pure managed code: a 3.1 MB DLL instead of a 600 MB browser
  • Never touches the network or your files unless you allow it
Program.cs
using PdfPecker;

byte[] pdf = HtmlToPdf.Convert("<h1>Hello</h1><p>World</p>");
File.WriteAllBytes("hello.pdf", pdf);

// Or straight from ASP.NET Core
app.MapGet("/invoice", () =>
    Results.File(HtmlToPdf.Convert(html), "application/pdf", "invoice.pdf"));

Or call the API

The same converter as an HTTP endpoint. Send HTML, Markdown or a file and get a PDF back; send a PDF to /api/pdf-to-image for PNGs.

curl -X POST "https://pdfpecker.net/api/convert?pageSize=A4&pageNumbers=true" \
     -H "Content-Type: text/html" --data-binary @invoice.html -o invoice.pdf

Made for templates you control

PdfPecker is a document engine, not a web browser. That is what makes it fast and small.

Great for

  • Invoices, payslips and receipts
  • Reports and statements
  • Tickets, labels and letters
  • Docs and READMEs from Markdown

Not for

  • Pages that need JavaScript to render
  • Screenshots of live websites
  • Fetching images from the web on its own
  • Right-to-left and complex scripts (yet)

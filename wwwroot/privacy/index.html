Privacy

What pdfpecker.net does with the documents you convert on it.

Documents you convert

The HTML to PDF and Markdown converters and the PDF tools (merge, organize pages, compress) send your document and settings to this site's server, which works on them in memory and sends the PDF, HTML or images straight back. The document is not stored, logged or kept after the response, and it is never shared with anyone. The server reads no files from its own disk for a conversion and fetches nothing from the network: remote images and stylesheets in your document are not loaded.

To keep the service fair, the server counts conversions per address for one minute, in memory only. That count holds no document content and is gone when the minute ends.

What stays in your browser

The site sets no cookies and runs no analytics, trackers or third-party scripts. The converters remember a few choices in your browser's local storage, such as whether the settings panel is open, and the Markdown converter keeps your current draft there so it survives a reload. None of it is sent anywhere; clearing the site's data in your browser removes it. A Markdown share link carries the document inside the link itself, so only people you give the link to can see it.

Hosting

The site runs on Cloudflare, whose network keeps the usual request records for security and reliability, such as the address, time and page of a request. They never contain the documents you convert.

Your own copy

PdfPecker is a library: in your own application, conversion runs in your process and nothing reaches this site. The source of the library and of this site is on GitHub.

Contact

Questions about this page or the library: open an issue on GitHub. Security problems: report them privately as described in the security policy.

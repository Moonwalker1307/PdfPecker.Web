HTML folder to PDF

Pick a folder and get a zip with a PDF of every .html file in it, in the same folders. Your files are processed in memory and sent straight back; nothing is stored.

or drop a folder here · up to 500 HTML files, 5 MB each with their images

An @page rule in a file's CSS wins over the page size here. Images, stylesheets and fonts the files use by relative path come along; files on the web are not fetched.

    In C#: HtmlToPdf.ConvertFile(path, pdfPath) for each file, with BaseDirectory so images and stylesheets load from disk. HTML to PDF in C#
